# 麻雀点数トレーナー

リーチ麻雀の点数計算を、理解して、反復して、身につけるための学習・練習アプリです。
ブラウザだけで動き、ビルドすると 1 枚の HTML になります（オフライン可）。

## できること（v0.1.0）

- **学習**: 点数計算の流れ（役 → 翻 → 符 → 点数）を 6 レッスンで解説
- **練習**: 実際の牌姿と場況から、翻・符・点数を回答。即時の解説つき
  - 難易度: 入門 / 標準 / 上級
  - 間違えた問題の復習キュー
- **点数表**: 子/親 × ツモ/ロン × 符 × 翻 の早見表
- **役一覧**: 門前/副露の翻数、成立条件、例つき
- **成績**: 正答率・連続正解・苦手な役（localStorage に保存）
