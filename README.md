# 麻雀点数トレーナー

リーチ麻雀の点数計算を、理解して、反復して、身につけるための学習・暗記・練習アプリです。
ブラウザだけで動き、ビルドすると 1 枚の HTML になります（オフライン可）。

## できること（v0.1.0）

- **ホーム**: 今日の成績、通算成績、学習進捗、苦手役 Top3、主要導線と「覚え方」への導線
- **学習**: 点数計算の流れを 6 レッスンで解説。各レッスン末に確認問題 3 問
  1. 点数計算の全体像（役 → 翻 → 符 → 点数）
  2. 役と翻（門前 / 副露、喰い下がり）
  3. 符の数え方（副底・面子・雀頭・待ち・ツモ / ロン、切り上げ）
  4. 点数表の読み方（基本点、満貫の境界）
  5. 満貫以上と支払い（跳満〜役満、子 / 親、本場・供託）
  6. 総合チェック（複合役・符の落とし穴）
- **覚え方**: 6 セクションの読み物（4 ステップ・符・点数表・役・反復・語呂）と 4 種類の暗記ドリル
  - 点数表穴埋め / 符カウント / 翻数カード / 支払いクイズ。すべて 4 択 + 解説
  - 正解で 1 → 3 → 7 → 14 → 30 日と間隔が伸びる間隔反復（SRS）。誤答は翌日
  - 学習レッスン 2〜5 から関連セクションへ移動
- **練習**: 実際の牌姿と場況から点数を回答。回答方式は 2 種類
  - 4 択: 正解 + 符違い / 翻違い / 満貫境界の近い誤答 3 つ
  - ステップ: 翻 → 符 → 点数の順に回答し、各段で即時フィードバック
  - ヒント（成立役・符の内訳）、キーボード操作、採点後の解説パネル
  - 誤答は自動で復習キューへ（最大 100 件、同じ問題は misses を加算）
- **点数表**: 子ロン / 子ツモ / 親ロン / 親ツモ の 4 タブ。20〜110 符 × 1〜13 翻 + 役満
  - 満貫以上は金、役満は朱。成立しないセルは「—」
  - 練習結果から該当セルへハイライト付きで移動
  - `@media print` で白背景・黒文字・ページ分割
- **役一覧**: 42 役の名前・読み・門前 / 副露の翻数・条件・複合の注意・例の牌姿
  - 検索、門前 / 副露 / 役満フィルタ、翻数ソート
  - 正答率の低い役に「苦手」バッジ
- **設定**: 回答方式、既定難易度、表示モード（2D / CSS 3D / リアル 3D）、牌サイズ、スート記号、アニメーション低減
  - 成績と復習のリセット / 全データ削除（確認ダイアログ）
  - ルールの前提とバージョン表示
- **3D 牌卓**: 練習の手牌だけを 3 モードで表示（回答 UI・解説・結果は 2D のまま）
  - CSS 3D: perspective で卓に置いたように傾ける。WebGL 不要・既定
  - リアル 3D: Three.js の牌卓。ドラッグで視点（左右 ±25° / 上下 ±10°）、ドラ表示牌・和了牌の金の縁
  - Three.js は選んだときだけ動的 import。WebGL 非対応・失敗時は CSS 3D に自動で戻す
- **牌**: 萬子・筒子・索子・字牌を実物風の SVG で描画（孔雀・竹・同心円・白の二重枠）
  - 象牙色の面・面取り・右側面の厚み・落ち影・深緑の裏面
  - 赤 5、和了牌の金の縁、副露の 90 度回転に対応

効果音はありません。外部フォント・画像・CDN・API へのリクエストもありません。

## 画面と操作

| 画面 | ハッシュ | 内容 |
|---|---|---|
| ホーム | `#/home` | 成績・進捗・主要 3 導線・苦手役 |
| 学習 | `#/learn` | 6 レッスン + 確認問題 |
| 覚え方 | `#/memorize` | 6 セクションの読み物・4 種類のドリル・SRS 成績 |
| 練習 | `#/practice` | 出題・回答・採点・解説・復習 |
| 点数表 | `#/chart` | 4 方向の早見表・印刷 |
| 役一覧 | `#/yaku` | 検索・フィルタ・ソート |
| 設定 | `#/settings` | 表示・出題・データ管理 |

デスクトップ（960px 以上）は左レール、タブレットは上部タブ、モバイル（640px 未満）は下部ナビです。
現在の画面は URL ハッシュに反映され、リロードしても復元されます。

| キー | 動作 |

| `Enter` | 次のステップへ / 次の問題へ |

| キー | 動作 |
|---|---|
| `1` 〜 `4` | 選択肢を選ぶ |
| `Enter` | 次の問題へ / 結果へ |

### 手牌の表示モード

設定画面の「表示モード」で切り替えます（既定は CSS 3D）。練習の出題カードの手牌だけが対象で、
回答ボタン・ヒント・解説・結果パネルは 2D のままです。

| モード | 内容 |
|---|---|
| 2D | 傾けない。軽量で最も読みやすい |
| CSS 3D | `perspective(1200px) rotateX(14deg)`。牌の下に影、和了牌は金の縁と発光。WebGL 不要 |
| リアル 3D | Three.js。深緑のフェルトに角丸の牌。ドラッグで視点移動、「視点をリセット」で戻す |

- リアル 3D は選んだときだけ Three.js を読み込みます（`React.lazy` + 動的 import）。
- WebGL が使えない環境や読み込みに失敗した場合は、自動で CSS 3D に切り替わり、その旨を表示します。
- `prefers-reduced-motion: reduce` では CSS 3D のホバー・トランジションを止めます（傾きは残ります）。
- 360px 幅では CSS 3D が 2〜3 段に折り返します。リアル 3D は牌が小さくなるため、狭い画面では CSS 3D / 2D を推奨します。
- 3D の canvas は `aria-hidden` で、同じ手牌を「二萬 三萬 …（和了牌）」の DOM テキストでも提供します。

## 開発

```bash
npm ci
npm run dev        # 開発サーバー
npm run typecheck  # 型チェック
npm run test       # テスト（Vitest）
npm run test:watch # テスト（監視）
npm run build      # dist/index.html（単一ファイル）
```

PowerShell の実行ポリシーで `npm` が止まる場合は `npm.cmd` を使ってください。

## 単一 HTML の配布

`npm run build` は `vite-plugin-singlefile` で JS・CSS をすべて `dist/index.html` にインライン化します。

- 出力は `dist/index.html` の 1 ファイルのみ
- `base: './'` なので `file://` で直接開ける
- 外部フォント・画像・CDN・API へのリクエストはありません（オフラインで完結）
- フォントは OS の日本語システムフォント（明朝 / ゴシック）を使用します
- three を含むビルドでも gzip で 400KB 以下（現在は約 275KB）です

## 保存データ

`localStorage` の `mst:v1:*` にのみ保存します。サーバー同期はありません。
スキーマ版（`mst:v1:schema`）を持ち、壊れた JSON・型不一致・旧スキーマは初期化して継続します（例外は投げません）。

| キー | 内容 |
|---|---|
| `mst:v1:settings` | 回答方式、既定難易度、表示モード、牌サイズ、スート記号、アニメーション低減 |
| `mst:v1:stats` | 出題数・正解数・連続・最高連続・役別成績・日別成績 |
| `mst:v1:review` | 復習キュー（最大 100 件。問題・正解・タグ・misses・追加日時） |
| `mst:v1:learn` | レッスン完了状態と確認問題の結果 |
| `mst:v1:drill` | ドリルのカード（習熟度・次回期限・正誤）とドリル成績 |

設定画面から「成績と復習をリセット」「全データを削除」ができます。

## ルールの前提

採点は `docs/RULES.md` の関東標準ルールに従います。設計とエンジン API は `docs/DESIGN.md` を参照してください。
主な前提は次のとおりです。

- 和了は「4 面子 + 1 雀頭」「七対子」「国士無双」のいずれか
- 役が 1 つもない手（ドラのみ）は和了できない
- 喰い下がり: 三色・一気・混全は 2→1、純全は 3→2、混一は 3→2、清一は 6→5
- 三色同刻は門前・副露ともに 2 翻
- 平和ツモは 20 符、平和ロンは 30 符、喰い平和形のロンは 20→30 符
- ロンで完成した刻子は明刻として扱う（符・三暗刻など）
- 連風牌の雀頭は +2 符（+4 にはしない）
- 役満は複合し、ダブル役満は 2 倍。役満時は通常役・ドラの翻を加算しない
- 13 翻以上は数え役満。5 翻または基本点 2000 以上は満貫
- 本場はロン +300 / ツモ各 +100、供託リーチ棒は 1000 点 × 本数

`computeScore` は不正な入力でも例外を投げず `{ ok: false, error }` を返します。
同じ入力と seed に対しては常に同じ結果になります（乱数は mulberry32、時刻依存なし）。
