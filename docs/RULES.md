# 採点ルール（v0.1.0 の唯一の正）

リーチ麻雀の一般的なルール（関東標準）を採用する。実装はこの文書と異なる解釈をしてはならない。
迷った場合は「天鳳」の公開ルールに合わせる。

## 1. 牌

- 数牌: `1m`〜`9m`（萬子）、`1p`〜`9p`（筒子）、`1s`〜`9s`（索子）。
- 字牌: `1z`=東、`2z`=南、`3z`=西、`4z`=北、`5z`=白、`6z`=發、`7z`=中。
- 赤 5: `0m` / `0p` / `0s`（= 5 の赤ドラ）。各種 1 枚まで。
- ドラ表示牌 → ドラ: 数牌は次の順（9→1）、風牌は東→南→西→北→東、三元牌は白→發→中→白。

## 2. 和了の成立

- 標準形: 4 面子 + 1 雀頭。七対子: 7 種の対子。国士無双: 13 種の幺九牌 + 1 枚。
- 役が 1 つもない手は和了できない（ドラのみは不可）。
- 喰い下がり: 下表の「副露」列。門前限定の役は副露で消える。
- 槓子は面子 1 つとして扱う（槓子上家からの大明槓、暗槓、加槓）。

### 複合の禁止

- `riichi` と `doubleRiichi` は同時に成立しない（doubleRiichi のみ）。
- `iipeikou` と `ryanpeikou` は同時に成立しない（ryanpeikou のみ）。
- `chanta`・`junchan`・`honroutou` は `honitsu`/`chinitsu` と複合する。
- `pinfu` と `chiitoitsu` は同時に成立しない。
- `toitoi` と `chiitoitsu` は同時に成立しない。
- `sanankou` は `toitoi` と複合する。

## 4. 符計算

| 項目 | 符 |
|---|---:|
| 副底 | 20 |
| 門前ロン | +10 |
| ツモ | +2（平和ツモは加算しない） |
| 待ち 単騎・嵌張・辺張 | +2 |
| 雀頭が役牌（三元牌・自風・場風） | +2 |
| 雀頭が連風牌（自風=場風） | +2（+4 とするルールは採用しない） |
| 中張牌の明刻 | 2 |
| 幺九牌の明刻 | 4 |
| 中張牌の暗刻 | 4 |
| 幺九牌の暗刻 | 8 |
| 中張牌の明槓 | 8 |
| 幺九牌の明槓 | 16 |
| 中張牌の暗槓 | 16 |
| 幺九牌の暗槓 | 32 |

- 七対子は 25 符固定（他の加算なし）。
- 喰い平和形（副露・全順子・非役牌雀頭・両面待ち）のロンは 20 符 → 切り上げで 30 符。
- 上記以外は合計を 10 の位に切り上げる（例: 32 → 40）。
- 平和ツモは 20 符。平和ロンは 20 + 10 = 30 符。
- 刻子がロンで完成した場合、その面子は明刻として扱う（符・暗刻数とも）。
- 槓子はすべて明槓/暗槓の符で数える（加槓は明槓）。

## 5. 点数

基本点 = 符 × 2^(翻+2)。以下で上限を適用する。

| 条件 | 基本点 | 名称 |
|---|---:|---|
| 役満 | 8000 × 役満数 | 役満 |
| 13 翻以上（数え役満） | 8000 | 数え役満 |
| 11〜12 翻 | 6000 | 三倍満 |
| 8〜10 翻 | 4000 | 倍満 |
| 6〜7 翻 | 3000 | 跳満 |
| 5 翻、または基本点 2000 以上 | 2000 | 満貫 |

支払い（100 点未満切り上げ）:

- 子ロン: 基本点 × 4
- 親ロン: 基本点 × 6
- 子ツモ: 子が基本点 × 1、親が基本点 × 2
- 親ツモ: 全員が基本点 × 2

本場: ロン +300/本場、ツモ 各 +100/本場。供託リーチ棒は和了者に 1000 × 本数。
支払いの `total` は本場・供託を含まない手の合計（ツモは 3 人分の合計）。

## 6. 不正入力

以下は `ok: false` を返す（例外を投げない）:

- 牌枚数が合わない、同じ牌が 5 枚以上、赤 5 が 2 枚以上。
- 和了牌が手牌にない。
- 門前なのに副露がある、副露の枚数と手牌枚数が矛盾。
- 槓子が 4 枚でない、順子が同種連番でない、刻子が同種同牌でない。
- 役がない（ドラのみ）。
- 同時に成立しない役の組み合わせを入力フラグで指定（例: `riichi` と `doubleRiichi`）。

## 7. 出題で使う場況

- `riichi` は standard 以上、`ippatsu` は上級のみ、`haitei`/`houtei`/`rinshan`/`chankan` は上級のみ。
- `honba` は上級のみ 0〜3、`riichiSticks` は上級のみ 0〜2。
- ドラ表示牌は 1〜3 枚（難易度による）。赤 5 は手牌に自然に含まれてよい。
- 天和・地和・人和・流し満貫は出題しない。
