# UI デザインガイド

「静かな牌卓」をコンセプトにする。深緑のフェルトに生成りの紙と牌が置かれ、
朱色は「いま触れるもの」だけに使う。賑やかさより、集中と余白。

## トークン

`src/styles/globals.css` の `@theme` に定義し、直値の色をコンポーネントに書かない。

| token | 値 | 用途 |
|---|---|---|
| `--color-felt-900` | `#0b2b22` | 画面背景の最深部 |
| `--color-felt-800` | `#103a2e` | 背景グラデーション |
| `--color-felt-700` | `#16483a` | パネル・レール |
| `--color-ivory-50` | `#f8f2e4` | カード面 |
| `--color-ivory-100` | `#efe6d3` | 牌の面 |
| `--color-ivory-200` | `#e2d4ba` | 罫線・区切り |
| `--color-ink-900` | `#1c1a16` | 本文の強 |
| `--color-ink-700` | `#3b372f` | 本文 |
| `--color-ink-500` | `#6d675b` | 補助文 |
| `--color-vermilion` | `#c94f3d` | 主要ボタン・現在地・誤答 |
| `--color-vermilion-soft` | `#e4775f` | ホバー・強調 |
| `--color-gold` | `#c9a227` | 点数・役満・達成 |
| `--color-jade` | `#4f9d69` | 正答 |
| `--color-line` | `rgba(248, 242, 228, 0.14)` | 暗い面の罫線 |

- 文字は暗い面では `ivory-50`、明るいカード面では `ink-900`。
- 朱色は 1 画面に 2 箇所まで。正答の緑と誤答の朱は意味のある色だけに使う。
- 色だけで正誤を伝えない。アイコン（○ / ×）と文言を必ず添える。

## タイポグラフィ

- 見出し: `"Yu Mincho", "Hiragino Mincho ProN", "Noto Serif JP", serif`。
- 本文: `"Yu Gothic UI", "Hiragino Sans", "Noto Sans JP", system-ui, sans-serif`。
- 数字（点数・翻・符）: `font-variant-numeric: tabular-nums`。
- 見出しサイズ: h1 28/36、h2 22/30、h3 17/24。本文 15/26。補助 13/20。
- 外部フォントを読み込まない。

## レイアウト

- デスクトップ（>= 960px）: 左レール 216px + 本文。本文は最大 1120px、中央寄せ。
- タブレット（640〜959px）: 上部に横スクロールのタブ。
- モバイル（< 640px）: 下部固定ナビ 64px + セーフエリア。本文は 16px 余白。
- 下部ナビは 7 項目（ホーム / 学習 / 覚え方 / 練習 / 点数表 / 役一覧 / 設定）。360px ではアイコン 18px・文字 9px で 1 行に収める。
- 画面の高さいっぱいに背景。カードは 1px の `ivory-200` 罫線 + 影 `0 12px 30px rgba(0,0,0,.18)`。
- 角丸はカード 16px、ボタン 10px、牌 6px。

## 背景

画像を使わず CSS のみ:

```css
background:
  radial-gradient(1200px 600px at 50% -10%, rgba(201,162,39,.10), transparent 60%),
  radial-gradient(900px 500px at 100% 100%, rgba(201,79,61,.06), transparent 60%),
  linear-gradient(160deg, #0b2b22, #103a2e 45%, #0b241d);
```

上に `repeating-linear-gradient` の微細ノイズ（不透明度 2%）を重ねてよい。

## 牌（`Tile`）

実物のリーチ麻雀牌に寄せた、SVG + CSS の牌面。画像・外部フォントは使わない。

- サイズ: sm 32×45、md 44×62、lg 58×80（px）。比率は約 1 : 1.4。練習の手牌は md、結果は sm。
- 本体: 象牙色のグラデーション `#fffdf5 → #f7f0dd → #eadcbe`、角丸 7px、内側 1px の罫線、
  右側面 3px の厚み、落ち影 `0 2px 0 #cbb78f, 0 3px 0 #b7a176, 0 8px 14px rgba(0,0,0,.4)`。
- 牌面は `viewBox="0 0 72 100"` の SVG。色は `TILE_FACE_COLORS` に定数で持ち、`currentColor` に依存しない。
- 萬子: 上に漢数字（一〜九）を墨、下に「萬」を朱。フォントは
  `"Yu Mincho", "Hiragino Mincho ProN", serif`。赤 5 は数字と「萬」の両方を朱にする。
- 筒子: 同心円のピップ。外輪は青 `#1f5f8a`、中輪は緑 `#2f7a4f`、中心は青。
  1 筒は 8 枚の花弁を添えた大きな花形、5 筒は中央の 1 個を朱にする。
- 索子: 竹の棒（節と小さな葉）。1 索は孔雀（扇尾・朱の尾羽先・金の嘴）。
  5 索は中央の 1 本を朱にする。配置は筒子と同じ（2 縦、3 斜め、4 四隅、5 四隅+中央、
  6 2×3、7 上 3 + 下 4、8 2×4、9 3×3）。
- 字牌: 東南西北は墨、白は無地に青灰 `#3c6e8f` の二重枠、發は緑、中は朱。文字は牌の高さの約 45%。
- 赤 5 は牌面の意匠をすべて朱にし、右上に小さな朱点を添える。`data-red="true"`。
- スート記号（萬/筒/索）は設定で牌面の下端に小さく添える（色覚に依存しない）。
- 和了牌は金の縁 `#c9a227` + 淡い発光 + `和了` ラベル。`aria-label` は「中（和了牌）」。
- 副露は右に 90 度回した牌 1 枚を含める。回転時は横幅が入れ替わる分の余白を確保し、下端を揃える。
- 裏面: 深緑 + 斜めの細格子 + 金の菱形。`aria-label` は「伏せ牌」。
- `aria-label` は「五萬」「東」など。SVG は `aria-hidden`。`data-tile` / `data-red` / `data-highlight` を維持する。
- 牌面の SVG 文字列は `src/components/tile/tileFaceSvg.ts` の `tileFaceSvg(tile)` が返す純粋関数。
  同じ牌は常に同じ文字列になり、3D（Three.js の CanvasTexture）からも再利用できる。
- 3D のテクスチャキーは `src/features/practice/scene/textures.ts`。34 種 + 赤 5（3 種）+ 裏 = 38 種で、
  同じ牌は常に同じキーになる。

## 画面ごとの要点

### ホーム
- 左上に「麻雀点数トレーナー」と小さな牌アイコン。
- 大きな 3 つの導線: 練習をはじめる（朱）/ 続きから学習 / 復習 N 問。
- 今日の成績は 3 つの数字を大きく。通算は小さな表。
- 苦手役 Top3 は役名 + 正答率 + 「練習する」。

### 学習
- 左にレッスン一覧（1〜6、完了チェック）、右に本文。
- 本文は 1 画面 1 トピック。図解は牌と式で構成。
- 確認問題は本文末尾にインライン。回答するとその場で解説が開く。

### 覚え方
- ハブ: 今日のドリル（10 問）、4 種類のドリルカード、6 セクションの一覧、ドリル成績。
- ガイド: デスクトップは左にセクション一覧、右に本文。モバイルは「一覧へ戻る」と前後移動。本文は段落・表・式・牌図・ミニ問題。表は横スクロール。
- ドリル: 上部に進捗（1/10）・正答率・連続。4 択は 2×2（360px は 1 列）。回答後に解説を開き、Enter で次へ。
- 結果: 正答数・正答率・最高連続・種類別の正答率と「次に伸ばす種類」。
- 正誤は ○ / × と文言で示す。キーボードは 1〜4 と Enter。効果音なし。

### 練習
- 上部: 難易度、問題番号、正答率、連続。
- 中央: 場況チップ（自風・場風・ツモ/ロン・リーチ・ドラ・本場・供託）→ 手牌 → 和了牌。
- 手牌だけを 2D / CSS 3D / リアル 3D（Three.js）で切り替えられる。回答 UI・解説・結果パネルは 2D のまま。
- 下部: 回答 UI。4 択は 2×2 の大きなボタン。ステップは翻 → 符 → 点数の 3 段。
- 採点後はカードをめくるように結果 panel を開く。点数は金の大きな数字。
- 「次へ」は Enter。結果 panel の下に「点数表で見る」「復習に追加」。

### 手牌の表示モード
- 設定の「表示モード」で選ぶ。既定は CSS 3D。`displayMode: '2d' | 'css3d' | 'three'`。
- **2D**: 傾けない。軽量で最も読みやすい。
- **CSS 3D**: 手牌コンテナに `perspective(1200px) rotateX(14deg)`。牌は `translateZ(6px)`、和了牌は
  `translateZ(14px)` で浮かせる。牌の下に接地域の影、和了牌は金の縁と淡い発光。
  副露は既存どおり右端の鳴き牌を 90 度回す。360px では 2〜3 段に折り返す。
  `prefers-reduced-motion: reduce` ではホバーとトランジションを止め、傾きだけ残す。
- **リアル 3D（Three.js）**: `React.lazy` + 動的 import。選んだときだけ読み込む。
  - 深緑のフェルト（roughness 0.97）、角丸の直方体（幅:高さ:厚み = 1 : 1.35 : 0.55）。
  - 牌面は `tileFaceSvg(tile, { showSuitMark: false })` を Canvas に描いた `CanvasTexture`
    （牌種ごとにキャッシュ、赤 5・字牌・裏を含む）。
  - 和了牌は金の縁 + emissive、ドラ表示牌は卓の右上に 0.62 倍で置く。
  - `OrthographicCamera` を `(0, 7.5, 9.5)` 付近から `lookAt(0, 0, 0)`。ドラッグで水平 ±25°、
    垂直 ±10°。ホイールは奪わない。「視点をリセット」ボタンとダブルクリックで戻す。
  - HemisphereLight + DirectionalLight + `Plane` + `ShadowMaterial` の接地影、`ACESFilmicToneMapping`。
  - DPR は最大 2、`ResizeObserver`、変化時だけ RAF を 1 回。タブ非表示・画面外では停止。
    アンマウント時に geometry / material / texture / renderer を dispose。
  - WebGL が使えない・読み込みに失敗した場合は CSS 3D に自動で戻し、その旨を表示する。
  - canvas は `aria-hidden="true"`。同じ手牌を「二萬 三萬 …（和了牌）」の DOM テキストでも出し、
    「和了牌: 六索」のラベルも添える。回答・ヒント・次へはすべて DOM のボタン。
  - 狭い画面では牌が小さくなるため、CSS 3D / 2D を推奨する。

### 点数表
- タブ 4 つ。表は横スクロール可。ヘッダー固定。
- 満貫以上は金の帯、役満は朱の帯。
- 現在の問題のセルは二重枠 + 朱の点。

### 役一覧
- 検索框 + フィルタ（すべて / 門前 / 副露 / 役満）。
- カード 2 列（モバイル 1 列）。役名 + 読み + 翻数バッジ + 条件 + 例の牌。
- 苦手役は「苦手」バッジ。

### 設定
- セクション: 回答方式 / 出題 / 表示モード / 表示 / データ。
- 表示モードは 2D / CSS 3D / リアル 3D の 3 枚のカードで、それぞれ小さなプレビューを添える。選択は即時反映・保存。
- 破壊的操作は朱の枠線ボタン + 確認ダイアログ。

## モーション

- 160〜240ms、`ease-out`。結果 panel は 8px 上からフェード。
- 連続正解は数字だけ 1.04 倍に弾ませる。
- CSS 3D の牌は 160ms で浮き上がる。3D の視点移動はドラッグに直接追従し、慣性アニメーションはしない。
- `prefers-reduced-motion: reduce` では全て 0ms。CSS 3D は傾きを保ち、ホバーとトランジションだけ止める。

## アクセシビリティ

- フォーカスリングは `2px solid var(--color-gold)` + offset 2px。
- タブは `role="tablist"` / `aria-selected`。画面切替時に見出しへフォーカスを移さない（読み上げの過剰移動を避ける）。
- 選択肢ボタンは `aria-pressed`。正誤は `role="status"` で通知。
- コントラスト比 4.5:1 以上（暗い面の補助文は 13px でも 4.5:1）。
